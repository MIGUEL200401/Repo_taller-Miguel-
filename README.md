# Repo_taller-Miguel-

## Descripción

Este proyecto corresponde a la creación de la **estructura base de un portafolio web** utilizando **HTML**, como parte del taller práctico de Git y GitHub.
El desarrollo se realizó en **Visual Studio Code** siguiendo un flujo de trabajo con ramas (`feature` y `develop`).

## Contenido del proyecto

* `index.html` → Estructura principal del portafolio
* `Styles.css` → Archivo de estilos (en desarrollo)
* `README.md` → Documentación del proyecto

## Estructura HTML incluida

El archivo `index.html` contiene una estructura semántica básica con:

* Encabezado (header)
* Sección **Sobre mí**
* Sección **Habilidades / Estudios**
* Sección **Proyectos y Aspiraciones**
* Pie de página (footer)

## Tecnologías utilizadas

* HTML
* CSS
* Git
* GitHub
* Visual Studio Code

## Flujo de trabajo

1. Creación del repositorio en GitHub
2. Creación de la rama `develop`
3. Desarrollo de la estructura HTML en una rama `feature`
4. Merge de `feature` → `develop`
5. Preparación del proyecto para futuras integraciones en `main`
